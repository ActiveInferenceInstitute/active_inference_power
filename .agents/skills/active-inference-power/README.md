# active-inference-power skill

Project-local workflow for the statistical package, its generated evidence,
and its bounded publication pipeline. See `SKILL.md` for the quick commands,
the [project contract](../../../AGENTS.md), and the
[documentation hub](../../../docs/README.md) for the detailed workflows. The
fast-bundle audit is a source-current, non-release integrity check; the
isolated candidate route remains the only path to sibling rendering and a
separately authorized finalization.
