# active-inference-power skill guide

Keep the three files in this folder aligned with the project root. The skill
must point at `active_inference_power`'s current package, evidence, and
publication boundaries—not at another sidecar or a generic template workflow.
When a command, generated-artifact contract, or validation order changes,
update `SKILL.md` and verify every relative link from this directory.
Keep the non-release fast-bundle audit separate from the isolated rendered
candidate chain, and carry reader-facing figure metadata—including
panel-specific validity for mixed-status visuals—through any workflow summary.
