# Manuscript syntax

Use Pandoc citations such as `[@benjamini1995controlling]`, labels such as
`{#fig:power-curve}` and `{#tbl:comparison}`, and cross-references such as
`[@fig:power-curve]`. For equations, prefer `$$ … $$ {#eq:label}`; the
renderer also accepts `\begin{equation}\label{eq:label} … \end{equation}`.
Reference either form with `[@eq:label]`. Never hardcode figure/table/equation
numbers or use raw `\ref{}`/`\eqref{}` in source Markdown.

All figure files are generated by `src/active_inference_power/figures/` from
`output/results.json`. Figure captions are generated in
`output/figures/figure_registry.json`, reused by the dashboard, and injected
into manuscript image descriptions through the corresponding
`{{FIGURE_*_CAPTION}}` tokens. Each image attribute block must also use its
matching `{{FIGURE_*_ALT}}` token so rendered alternative text remains a
visual description rather than a duplicate caption. Use `{{FIGURE_ERROR_BAND}}` for shared
Monte-Carlo error-band prose so counts, confidence levels, and validity
boundaries cannot drift from the result artifact.

## Variable tokens

Use uppercase tokens for changing values, for example
`{{RESULT_BH_FDR}}` or `{{QUALITY_BRANCH_COVERAGE}}`. The live token test scans
manuscript source and fails if a token is not generated. Do not put illustrative
token syntax in a manuscript section that the scanner treats as live prose.
