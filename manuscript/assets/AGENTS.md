# Manuscript assets agent guide

This directory contains authored publication source assets only. The cover art
is not a generated figure, model output, or evidence for a scientific claim;
never place result-bearing text, numerical annotations, or generated artifacts
here.

If replacing a source asset, update the corresponding `paper.cover` reference
and provenance documentation with the file name, SHA-256, creator/source
statement, rights, and non-scientific role, then regenerate and inspect the
rendered title page through the normal publication pipeline. Do not edit
`output/` to repair an asset or use an asset change to imply a new publication,
DOI, or result.
